🇯🇵 日本語 (Japanese)

本プライバシーポリシーは、Chrome拡張機能「🍌 BananaX」（以下「本拡張機能」）におけるユーザー情報の取り扱いについて説明します。

1. 取得・処理する情報

本拡張機能は、インフォグラフィック画像の生成および機能提供のために以下の情報を取り扱います。開発者独自のバックエンドサーバーは存在せず、以下のデータはいずれもユーザーのブラウザ内またはユーザーが指定したAI APIプロバイダーとの直接通信でのみ処理されます。

  1. AI APIキー（Google Gemini APIキー / OpenAI APIキー）
    • ユーザーが設定画面（ポップアップまたはオプション画面）で入力したAPIキーを取得します。
    • APIキーはユーザーのブラウザ内（chrome.storage.local および chrome.storage.sync）にのみ保存され、開発者のサーバーや第三者へ送信されることはありません。
    • 設定のJSONバックアップ出力（エクスポート）機能を実行した際も、セキュリティ保護のためAPIキーは自動的に除外されます。
  2. X（旧Twitter）の投稿テキスト・文脈情報・参照画像
    • ユーザーがXの投稿作成画面で「🍌」ボタンをクリックして画像生成を実行した際、入力中のテキスト、返信元・引用元の投稿テキスト（文脈理解のため）、およびユーザーが任意で登録した参照画像（キャラ・スタイル・ロゴ固定機能）を読み取ります。
    • これらの情報は、インフォグラフィック画像を生成する目的でのみ、ユーザーが選択したAI APIエンドポイントへブラウザから直接HTTPS送信されます。
  3. ローカル保存される設定・履歴データ（ブラウザ内完結）
    • カスタムプロンプトパターン、アスペクト比、UI言語、選択中のAIモデル（gemini-nano-banana-2.1 / gpt-image-2.6-flare）
    • マイブランドカラー設定（プライマリカラー・アクセントカラー・背景トーン）
    • クレジット透かし設定（@handle 等のテキストおよびON/OFF状態）
    • 参照画像データおよび直近の生成履歴（最大20件、chrome.storage.local に保存）
    • 透かし合成（Canvas処理）、クリップボードへのPNG画像コピー、アクセシビリティ用ALTテキスト生成、設定JSONのエクスポート／インポートはすべてブラウザ内（クライアントサイド）で完結します。

2. 外部通信先とデータの送信

  • Google Gemini API (https://generativelanguage.googleapis.com/*): ユーザーがGeminiモデルを選択して画像生成を実行した際、ユーザーのGemini APIキーを用いてGoogleのAPIサーバーへプロンプト・投稿文脈・参照画像を直接送信します。
  • OpenAI Images API (https://api.openai.com/*): ユーザーがOpenAIモデルを選択して画像生成を実行した際、ユーザーのOpenAI APIキーを用いてOpenAIのAPIサーバーへプロンプト・投稿文脈・参照画像を直接送信します。
  • スタイル見本・人気ランキングカタログ (https://furoku.github.io/*): ポップアップ内の「人気ランキング」タブ等を表示する際、公開されている静的カタログJSONおよびサムネイル画像を読み取るためにのみアクセスします。ユーザーの個人情報や投稿データが送信されることはありません。

3. 第三者提供・トラッキングの禁止

  • 開発者は、ユーザーのAPIキー、投稿内容、生成画像、閲覧履歴などを収集・保存・閲覧するサーバーを持たず、第三者への販売・提供・貸与を一切行いません。
  • 本拡張機能には外部アクセス解析ツール（Google Analytics等）、広告SDK、テレメトリ送信コード、リモートコード実行機能は一切含まれていません。
  • GoogleおよびOpenAIにおけるAPI通信データの取り扱いは、各社が定める利用規約およびプライバシーポリシーに従います。

4. データの管理と削除

  • ポップアップ内の「履歴をすべて削除」や参照画像の「クリア」、またはAPIキー欄を空にして保存することで、いつでも保存データを消去できます。
  • Chromeブラウザから本拡張機能をアンインストールすると、ローカルストレージのデータも削除されます。

5. お問い合わせ

本プライバシーポリシーに関するお問い合わせは、開発者連絡先（X: @furoku）までお願いいたします。

🌐 English

This Privacy Policy explains how the Chrome extension "🍌 BananaX" ("the Extension") handles user data.

1. Data Collected and Processed

The Extension does not operate any proprietary backend servers. All data is stored locally in your browser or sent directly from your browser to the AI API provider you configure:

  1. AI API Keys (Google Gemini API Key / OpenAI API Key)
    • Stored exclusively in your browser (chrome.storage.local and chrome.storage.sync).
    • Never transmitted to the developer or any third party other than the official API endpoint you select.
    • Automatically stripped and excluded when exporting settings via the JSON Backup feature.
  2. X (formerly Twitter) Post Text, Context, and Optional Reference Images
    • Read only when you explicitly click the "🍌" button in the X post composer to generate an infographic.
    • Sent directly over HTTPS from your browser to your selected AI API provider (generativelanguage.googleapis.com or api.openai.com) solely to generate the requested image.
  3. Locally Stored Preferences & Generation History (100% Client-Side)
    • Custom prompt patterns, aspect ratio, language, selected AI model, Brand Color Palette settings, Credit Watermark (@handle) settings, optional reference image, and up to 20 recent generation history items are stored in chrome.storage.local / chrome.storage.sync.
    • Watermark compositing (HTML5 Canvas), 1-click PNG clipboard copying, Auto-ALT text generation, and JSON settings backup/restore all run 100% locally inside your browser.

2. External Network Requests

  • Google Gemini API (https://generativelanguage.googleapis.com/*): Direct API calls using your Gemini API key when generating images with Gemini.
  • OpenAI Images API (https://api.openai.com/*): Direct API calls using your OpenAI API key when generating images with OpenAI.
  • Public Style Catalog (https://furoku.github.io/*): Read-only fetch of public static infographic style rankings and thumbnails. No user data is transmitted.

3. No Tracking, Analytics, or Remote Code

  • The Extension contains no analytics, no telemetry, no ad trackers, and no remote code execution.
  • We do not collect, sell, rent, or transfer any user data to third parties.

4. Contact

For questions regarding this Privacy Policy, please contact the developer via X (@furoku).
